
# 👟 Shoe Company
 
A modern and responsive shoe company landing page built using **HTML5** and **Tailwind CSS**. The project showcases premium footwear collections with a clean design.
 
## 🚀 Features
 
- Responsive design
- Modern UI/UX
- Product showcase section
- Customer testimonials

 
## 🛠️ Tech Stack
 
- HTML5
- Tailwind CSS
